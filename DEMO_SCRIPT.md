# Demo script (3 min)

**0:00 — Hook (15s)**
"In Queens, it's hard to know which courts are open, which trails are busy, or where to volunteer. OutHere puts it all on one map."

**0:15 — Home (25s)**
- Sign in → **Demo User**.
- Greeting, live weather, **For you** carousel. Point at a reason line: "Basketball · 1.5 mi · Sunny 55°".
- Scroll: **Near you** with live Quiet / Active / Busy.

**0:40 — Explore (40s)**
- Tap **Explore**. Filter chip **Basketball**, then **Quiet now**.
- Tap a pin → sheet: amenities, weather, activity, **Directions**, **Save**.
- Tap **I'm here** (explain: only within 300 m, counts only, expires in 90 min).

**1:20 — Discover + RSVP (35s)**
- **Discover** → sort **For you** → filter **Family** / **Verified**.
- Open **Alley Pond Tulip Tree Hike**: forecast, safety card, host badge. Tap **Going**. **Share**.

**1:55 — Create (25s)**
- Center **+**. Search "Kissena", pick the park. Title, time. Try adding a phone number → blocked.
- Post.

**2:20 — Activity (20s)**
- **Activity**: start timer, volunteer hours card, chart, streak, milestones. **CSV** export.

**2:40 — Trust & safety (15s)**
- Sign out → **Demo Admin** → **Admin**: report queue (Dismiss / Hide / Suspend), approve a verified org.

**2:55 — Close (5s)**
"Free to run, works on any phone. OutHere — get outside."
